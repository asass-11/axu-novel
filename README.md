# 阿序AI 长篇小说工作流 4.0

一个让 AI 带你写长篇网文的 Skill。装好以后，跟它说一句“开一本新书”，它会一步一步问你想写什么，陪你定方案、排大纲，再一章一章往下写，一卷写完帮你收卷、排下一卷，直到完本。

你只需要干两件事：它问，你答；它写，你审。

## 它能帮你做什么

- **开书一步一停。** 从“你想写什么”问起，给你的脑洞做体检，出三个故事方案让你挑，搭世界和人物，排前三章。每一步都等你点头再往下走。
- **故事不是一条直线。** 排细纲时用九个问题检查，防止事情一件接一件、互不影响，或者每章都只是在回答上一章。
- **写完先自查。** 每章写完，先按一套去 AI 味的规则查一遍：人物做事有没有自己的理由，反应和事情大小对不对得上，有没有多余的解释，再交给你。
- **长篇不忘事。** 人物、伏笔、时间线、你否掉的设定，都记在你电脑上的项目档案里。换一个对话，它先读档案，告诉你停在哪，接着写。
- **你没认可的不算数。** 它写的每一章先算候选，你说采用了，才存进正文、更新记录。

## 怎么装

需要一个能读写你电脑文件、能加载 Skill 的 AI 智能体。网页聊天框用不了。

把整个 `axu-novel` 文件夹（不要只拷 SKILL.md）复制到智能体的 Skill 目录里：

| 智能体 | 放到这里 |
| --- | --- |
| Claude Code | `用户文件夹/.claude/skills/axu-novel/` |
| Codex | `用户文件夹/.agents/skills/axu-novel/` |

“用户文件夹”在 Windows 上一般是 `C:\Users\你的用户名`，在 Mac 上是 `/Users/你的用户名`。装一次，以后开哪本书都能用。已经有旧版的，先把旧的整个文件夹移到所有 Skill 扫描目录以外备份，再放新的；不要只在原 Skill 目录里改名，以免新旧版本同时被加载。

其他支持 Skill 的智能体，按它自己的说明放进 Skill 目录就行。

## 怎么开始

新开一个对话，说：

> 开一本新书。

它会先问你项目放在哪个文件夹，然后开始问你想写什么。如果它没反应过来，就说得明白一点：“用 axu-novel 这个 Skill，帮我开一本新书。”在 Claude Code 里也可以直接输入 `/axu-novel`。

换了对话想接着写，说：

> 接着写我的小说，项目在（你的小说文件夹）。

已经有自己的设定或写好的章节，直接告诉它哪些是定下的、哪些只是草稿，它会从缺的那一步开始，不会推翻重来。

两件事知道一下：

- **查榜单要能联网。** 开书第二步它会去看读者现在在追什么。不能联网或你不想查，跟它说跳过就行。
- **前三章的冷读要能开子智能体。** 每写完一章，它会另找一个没看过大纲的 AI 当读者挑毛病。你用的智能体开不了，就自己新开一个对话，把这一章贴进去，让它当读者读一遍。

附带样章供写法参考，创作时请尊重原创、合理使用参考材料。

## 还不完善

这套 Skill 可能还有不完善的地方。你用着哪儿别扭、哪一步卡住了，欢迎告诉阿序AI，也欢迎直接改了分享出来，大家一起把它补完。

AI 写出来的东西好不好，最后还是你说了算。它能帮你少走弯路，不能保证签约、成绩或收入。
